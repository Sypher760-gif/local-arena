# Active question provenance

The distributed corpus contains the 704 selected candidate rows used by app/data/questions-hard. tools/build_hard_bank.py preserves source URLs, licenses, source positions, edits and notes. THIRD_PARTY_NOTICES.md lists attribution and license scope. docs/licenses contains the notices and legal texts.

The original survey considered more sources. Unused rows, including sources with unresolved underlying rights, are excluded from this release. MATH-500 rows retain the note explaining their upstream-license inference.
